# 수기 영수증 텍스트 데이터 추출 분석

> 수기 영수증 이미지를 업로드하여 인식된 데이터를 확인하고 수정·저장할 수 있는 웹 서비스

## 프로젝트 개요

수기 영수증을 이미지로 업로드하면 OCR을 통해 추출된 데이터를
사용자가 확인하고 수정할 수 있는 웹 서비스를 개발했습니다.

인식된 영수증 데이터는 화면에서 수정 및 저장할 수 있으며,
업체명과 물품명 등을 기준으로 데이터를 검색하고
Excel 파일로 다운로드할 수 있도록 구현했습니다.

### 프로젝트 목적

- 수기 영수증 데이터의 디지털화
- OCR 인식 결과의 확인 및 수정 기능 제공
- 영수증 데이터의 검색 및 조회 편의성 향상
- 인식 데이터를 Excel 파일로 다운로드할 수 있는 기능 제공

## 주요 구현

### 1. 전역 상태 관리 (Recoil)

OCR 인식 결과와 로그인 토큰처럼 여러 화면에서 공통으로 사용하는 데이터를 관리하기 위해 Recoil Atom을 활용했습니다.
`receiveData`, `userToken` 두 개의 atom으로 상태를 전역 관리했고,
`userToken`의 초기값을 `localStorage.getItem('token')`으로 설정하여
새로고침 후에도 로그인  상태가 유지되도록 구현했습니다.

### 2. 로그인 / 회원가입

로그인 성공 시 응답 헤더에서 Authorization 토큰을 추출하여
`localStorage`와 Recoil atom에 함께 저장하고, 이후 요청에서 이 토큰을
활용해 인증 상태를 유지하도록 구현했습니다.

회원가입 시에는 이메일 중복 확인 API를 별도로 호출하고, 비밀번호와 비밀번호
확인 값의 일치 여부를 클라이언트에서 먼저 검증하도록 구현했습니다.

### 3. 영수증 업로드

사용자가 편하게 영수증 이미지를 업로드할 수 있도록 `react-dropzone`을 활용한
드래그 앤 드롭 업로드와 기존 파일 선택(`input[type=file]`) 두 가지 방식을 함께 지원했습니다.

`FileReader`로 업로드한 이미지의 미리보기를 생성해 보여주고, `FormData`로 서버에 이미지를 전송한 뒤 OCR 처리 응답을 기다리는 동안에는 로딩 화면으로 전환하도록 구현했습니다.

### 4. OCR 인식 결과 확인 및 수정

인식된 영수증 데이터를 사용자가 직접 확인하고 고칠 수 있도록 품목·단가·수량·금액을 테이블 형태로 렌더링했습니다.

단가나 수량을 수정하면 해당 행의 금액과 전체 합계가 실시간으로 재계산되도록 구현했고, 선택한 행을 기준으로 품목을 추가·삭제할 수 있는 기능도 함께 구현했습니다.

### 5. 영수증 목록 조회 및 검색

로그인한 사용자의 영수증 목록을 서버에서 조회하고, 업체명/물품명 기준 검색과 거래 기간(시작일~종료일) 필터링을 동시에 적용할 수 있도록 구현했습니다.

목록이 길어질 경우를 대비해 `react-js-pagination`으로 페이지네이션을 구현했습니다(1페이지당 10건).

### 6. 영수증 상세 조회 / 수정 / 삭제 / 엑셀 다운로드

URL 파라미터(`receiptId`)로 특정 영수증의 상세 데이터를 조회하도록 구현했고, 단가·수량을 수정하면 금액과 총액이 자동으로 재계산되도록 했습니다.

수정된 내용은 PUT 요청으로 저장하고, 필요 시 DELETE 요청으로 삭제할 수 있도록 구현했으며, `xlsx` 라이브러리를 활용해 영수증 데이터를 Excel 파일로 다운로드할 수 있는 기능도 함께 구현했습니다.

1. **영수증 처리 방식**: 도매 거래 시, 수기 및 인쇄 영수증 혼재.
